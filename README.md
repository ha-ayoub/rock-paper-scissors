<h2 id="fr">🇫🇷 Version Française</h2>
Ce projet est une version moderne et animée du célèbre jeu Pierre–Feuille–Ciseaux, développée avec React, TypeScript et CSS.
L’objectif est de proposer une expérience fluide, ludique et visuellement agréable, grâce à des animations dynamiques et une interface responsive.

Le joueur affronte l’ordinateur dans une partie aléatoire : chaque tour révèle un effet visuel animé lorsque les choix apparaissent, puis affiche le résultat (gagné, perdu ou égalité).

Ce projet a été conçu pour pratiquer React avec Javascript, la gestion d’état, et la création d’interfaces interactives avec des animations CSS.

✨ Fonctionnalités

        Jeu Pierre – Feuille – Ciseaux entièrement interactif
        Animations fluides et transitions CSS élégantes
        Interface responsive compatible mobile et desktop
        Système de score et de résultat instantané
        Design moderne et minimaliste

<h2 id="en">🇬🇧 English Version</h2>

This project is a modern and animated version of the classic Rock–Paper–Scissors game, built with React, TypeScript, and CSS.
It delivers a smooth, fun, and visually appealing experience, featuring dynamic animations and a responsive layout.

The player competes against the computer in random rounds — each choice triggers a beautiful animation, followed by the result display (win, lose, or draw).

The project focuses on practicing React with Javascript, state management, and creating interactive UI with CSS animations.

✨ Features

Fetches Sudoku boards from sudoku-api.vercel.app🔗

        Fully interactive Rock–Paper–Scissors game
        Smooth transitions and elegant CSS animations
        Built with React + TypeScript
        Responsive design for all devices 
        Real-time score tracking and instant results
        Clean and minimal modern UI
